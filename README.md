# Landing tipo Linktree — Plantilla

Esta es una landing estática simple con estilo y comportamiento similar a Linktree. Incluye un perfil, bio y una lista de enlaces que se pueden personalizar desde `js/main.js`.

Archivos principales:

- `index.html` — HTML de la landing.
- `css/style.css` — Estilos responsivos.
- `js/main.js` — Datos de enlaces y lógica (genera botones y copia enlaces al portapapeles).

Cómo usar:

1. Clona o descarga el repositorio.
2. Abre `index.html` en tu navegador (doble clic o `File → Open`).
3. Edita `js/main.js` para cambiar los enlaces, títulos y descripciones.

Despliegue rápido (GitHub Pages):

1. Sube el repositorio a GitHub.
2. En la repo, ve a Settings → Pages y selecciona la rama `main` y la carpeta `/ (root)`.
3. Espera unos minutos y tu landing estará disponible en `https://<tu-usuario>.github.io/<tu-repo>`.

Siguientes mejoras sugeridas:

- Añadir un panel de administración para editar enlaces desde la UI.
- Guardar enlaces en JSON externo o en localStorage para edición desde el navegador.
- Integrar analytics y meta tags para mejorar el SEO & social preview (Open Graph).
